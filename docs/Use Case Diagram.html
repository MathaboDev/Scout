Actor summary

ActorScope
StudentOwns a profile and documents, browses and applies for opportunities, tracks outcomes, receives notifications.
ProviderPosts opportunities, reviews applicants, updates application outcomes. Every new listing enters the admin queue.
AdministratorReviews pending listings in the verification queue; approving one makes it visible to students (FR9).

Include / extend

  • Register «includes» Verify email via OTP — a registration is only complete after OTP verification.
  • Submit application «includes» Upload documents — missing required documents route the student into upload before the review screen (FR4).
  • Post opportunity «extends» Review verification queue — every new listing extends into the admin queue automatically.
